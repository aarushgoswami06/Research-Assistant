# AI Research Assistant

## Goal

Build an AI-powered research assistant that can:

- Upload PDFs
- Answer questions using RAG
- Show citations
- Store chat history
- Authenticate users
- Deploy online

## Tech Stack

Frontend
- React
- TypeScript
- Tailwind CSS

Backend
- FastAPI

AI
- LangChain
- Gemini/OpenAI
- Sentence Transformers

Database
- PostgreSQL
- ChromaDB
